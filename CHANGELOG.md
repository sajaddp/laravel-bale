# Changelog

All notable changes to this package are documented here.

## Unreleased

## 1.0.0

- First stable Bale Bot API client for Laravel 13 and PHP 8.3+, covering messaging, webhooks, polling, callbacks, message operations, and `askReview`.
- Media and file support, including multipart uploads, media groups, `getFile`, and the `downloadFile` convenience.
- Laravel-native `replyToMessage` convenience plus `Bale::fake()` and request assertions for integration tests.
- Laravel Boost guidance, a Bale development skill, and reference documentation for supported and unsupported Bale APIs.
- `replyToMessage` and `downloadFile` convenience workflows that compose official Bale requests.
- Persian README and repository reference documentation.
