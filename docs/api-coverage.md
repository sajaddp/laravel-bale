# پوشش رابط برنامه‌نویسی بازوی بله

این فهرست همهٔ متدهای رابط برنامه‌نویسی بازو در متن اچ‌تی‌ام‌ال رسمی بله را در بر می‌گیرد؛ نوع‌ها، مینی‌اپ و رابط‌های برنامه‌نویسی جاوااسکریپت در این جدول نیستند. «پشتیبانی‌شده» یعنی متدی عمومی و مستقیم در لاراول بله وجود دارد. هیچ زمان‌بندی انتشار یا سازگاری استنباطی مطرح نیست.
