# رفع اشکال

## `BALE_BOT_TOKEN` تنظیم نشده است

پکیج پیش از ساخت URL، توکن خالی یا غیررشته‌ای را با `LogicException` رد می‌کند. `BALE_BOT_TOKEN` را در محیط برنامه تنظیم کنید و کش پیکربندی را متناسب با استقرار خود نوسازی کنید.

## نوع خطا چیست؟

- `BaleRequestException`: Bale یک ساختار پاسخ معتبر با `ok: false` برگردانده است.
- `RequestException`: پاسخ HTTP ناموفق یا دانلود محتوای دودویی ناموفق است که ساختار پاسخ معتبر Bale ندارد.
- `UnexpectedValueException`: پاسخ موفق، `result` یا اطلاعات فایل با قرارداد مورد انتظار سازگار نیست.

## وب‌هوک 419 یا URL اشتباه

در `routes/web.php`، POST خارجی Bale توکن CSRF ندارد. دقیقاً همان نشانی وب‌هوک را در `bootstrap/app.php` از CSRF خارج کنید؛ مثلاً `bale/webhook`. یا مسیر را با طراحی امنیتی خودتان در محل مناسب قرار دهید. URL داده‌شده به `setWebhook` باید URL عمومی دقیق همان مسیر باشد. پکیج مسیر، کنترل‌کننده یا اعتبارسنجی راز نمی‌سازد.

## مسیر محلی رشته‌ای آپلود نمی‌شود

رشته در API رسانه فقط `file_id` بله یا HTTP URL است. برای آپلود، `SplFileInfo` بدهید:

~~~php
new SplFileInfo(storage_path('app/file.pdf'))
~~~

## `replyToMessage` خطا می‌دهد

ورودی باید دادهٔ خام Bale Message با `message_id` و `chat.id` عددی باشد. شیء، رشته یا Message ناقص را تبدیل نکنید؛ دادهٔ Update را همان‌طور که دریافت شده بررسی کنید.

## فایل دانلود نشد

`downloadFile` ابتدا `getFile` را فراخوانی می‌کند. نتیجه باید `file_path` غیرخالی داشته باشد، وگرنه `UnexpectedValueException` رخ می‌دهد. URL دانلود حاوی توکن است؛ آن را ثبت گزارش یا عمومی نکنید. برای تازه‌ماندن لینک، در هر دریافت از `getFile` جدید استفاده کنید.

## `attach://` برای گروه رسانه کار نمی‌کند

هر ارجاعی مانند `attach://first` باید یک فایل پیوست با کلید دقیق `first` و `SplFileInfo` قابل‌خواندن داشته باشد. برای آپلود `multipart`، پکیج فیلدهای JSON مانند `media` را سریال‌سازی می‌کند.

## دریافت دوره‌ای بیش از انتظار طول می‌کشد

`getUpdates` در دریافت طولانی‌مدت فقط یک درخواست می‌سازد. `timeout` Bale را در `options` قرار دهید؛ پکیج برای زمان‌انتظار HTTP مهلت اضافی مناسب می‌افزاید. حلقه، صف، فاصلهٔ افزایشی تلاش مجدد و ذخیرهٔ `offset` جزو این پکیج نیستند.

## فرض نکنید رفتار Telegram برقرار است

شباهت نام‌ها به معنی سازگاری متد API، فیلد یا نتیجه نیست. [پوشش رسمی Bale](api-coverage.md) را بررسی کنید؛ API پشتیبانی‌نشده را با متد کمکی یا متد خیالی جایگزین نکنید.
